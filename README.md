# 영화 예매 도우미 (메가박스·롯데시네마·CGV)

영화·지점·날짜·시간·좌석(1~10순위)까지 고르고 **결제 직전에 멈추는** 개인용 프로그램.
로봇 확인과 결제 단계는 직접 누른다.

**설정 만들기 사이트**: https://treditor88.github.io/megabox-helper/ — 영화관을 고르고 좌석표를 눌러 1~10순위를 정한 뒤 `config.json` 을 받는다.

## 준비
```
pip install playwright
python -m playwright install chromium
```

## 사용
1. `config.json` 을 고친다(영화관 `cinema`: `megabox`/`lotte`/`cgv`, 영화·지역·지점·날짜·시각·인원·좌석 순위·줄).
2. `python megabox_helper.py` → 처음 한 번 열린 창에서 직접 로그인(상태는 `profile\`, CGV 는 `profile_cgv\` 에 저장).
3. 좌석이 골라지면 소리가 나고 멈춘다. 창에서 확인 후 다음 단계를 눌러 결제.

- `--dry` : 로그인 없이 고를 회차만 보여 줌
- `python test_seats.py` : 좌석 순위 고르기 시험

### 폰에서 쓰기
프로그램은 PC 크롬 창에서 돌아서, 폰에서는 PC 화면을 원격으로 본다.
1. PC 에 **Chrome 원격 데스크톱**(remotedesktop.google.com/access)을 설치하고 PIN 을 정한다. 폰에도 같은 앱을 깔고 같은 구글 계정으로 로그인.
2. 폰 앱으로 PC 에 들어가 바탕화면의 **영화 예매 도우미** 바로가기를 누른다(= `python megabox_helper.py`). PC 는 켜져 있고 절전이 꺼져 있어야 함.
3. 좌석이 골라져 멈추면 휴대폰 알림이 온다(이 PC 에 HEO Works 워커 키 `..\study-helper\sync.json` 이 있을 때만). 원격 화면에서 확인하고 직접 결제.

### 영화관별 상태
| | 회차 고르기 | 좌석 고르기 |
|---|---|---|
| 메가박스 | 실제 사이트에서 확인 | 로그인 뒤 화면이라 아직 실제 확인 못 함 |
| 롯데시네마 | 실제 사이트에서 확인 | 좌석 화면 구조를 못 봐서 추정으로 만듦 — 안 되면 좌석은 직접 고르게 멈춤 |
| CGV | 실제 사이트에서 확인 | 로그인 뒤 화면이라 추정으로 만듦 — 안 되면 좌석은 직접 고르게 멈춤 |

**CGV 는 설치된 Chrome 으로만** 연다. CGV(Cloudflare)가 Playwright 의 Chromium 과 창 없는 실행을 403 으로 막기 때문(`--dry` 도 Chrome 창이 잠깐 뜸). 예매 화면 이름표(class)에 업데이트마다 바뀌는 꼬리가 붙어서 앞부분으로만 찾지만, 화면이 크게 바뀌면 고장 날 수 있음.

각 영화관 약관은 자동 프로그램 사용을 금지한다. 내 예매에 가끔만, 짧은 간격 반복 확인 없이 쓸 것.
