# 메가박스 예매 도우미

영화·지점·날짜·시간·좌석(1~10순위)까지 고르고 **결제 직전에 멈추는** 개인용 프로그램.
좌석 화면의 '다음'(로봇 확인 + 결제)은 직접 누른다.

## 준비
```
pip install playwright
python -m playwright install chromium
```

## 사용
1. `config.json` 을 고친다(영화·지역·지점·날짜·시각·인원·좌석 순위·줄).
2. `python megabox_helper.py` → 처음 한 번 열린 창에서 직접 로그인(상태는 `profile\` 에 저장).
3. 좌석이 골라지면 소리가 나고 멈춘다. 창에서 확인 후 '다음'을 눌러 결제.

- `--dry` : 로그인 없이 고를 회차만 보여 줌
- `python test_seats.py` : 좌석 순위 고르기 시험

메가박스 약관은 자동 프로그램 사용을 금지한다. 내 예매에 가끔만, 짧은 간격 반복 확인 없이 쓸 것.
