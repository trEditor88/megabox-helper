좌석까지 골라 두고,
결제는 직접.

영화·지점·날짜·시간·좌석 1~10순위를 정해 두면, 프로그램이 메가박스·롯데시네마·CGV에서 그대로 고르고 결제 직전에 멈춥니다. 롯데시네마·CGV 좌석 고르기는 아직 시험 중이라, 안 되면 좌석만 직접 고르게 멈춰요.

설정 만들기설치·실행 방법

어떻게 움직이나요

이 사이트는 설정 파일만 만들어요. 예매는 내 PC에서 돌아가는 프로그램이 크롬 창을 열어 진행합니다.

  1. 1. 로그인처음 한 번, 열린 창에서 직접 로그인해요. 비밀번호는 프로그램이 다루지 않아요.
  2. 2. 회차 고르기날짜·지점·영화를 고르고, 원하는 시각에 가장 가까운 회차를 찾아요.
  3. 3. 좌석 고르기1순위부터 차례로, 모든 자리가 비어 있는 순위를 골라요.
  4. 4. 멈춤소리가 나면 창에서 확인하고 '다음'을 직접 눌러 결제해요.

설정 만들기

입력하면 오른쪽에 config.json이 바로 만들어져요. 받은 파일을 프로그램 폴더에 넣으면 끝이에요.

영화와 회차

좌석 순위

순위를 고른 뒤 좌석표에서 인원 수만큼 눌러요. 다 채우면 다음 순위로 넘어가요. 상영관마다 배치가 다르니 예매 사이트 좌석표를 보고 이름(예: G7)을 맞춰 주세요.

    설치·실행
    
  
    Windows PC 기준이에요. 파이썬이 없으면 python.org 에서 먼저 설치해 주세요.
    
  
      
    
    1. 프로그램 받기
      압축을 풀면 megabox_helper.py가 든 폴더가 생겨요.
      ZIP 받기
      2. 
    
    2. 준비 한 번
      명령 창(PowerShell)에서 한 줄씩 실행해요.
      
      
      pip install playwright
      
      
      python -m playwright install chromium
      
      
      CGV는 PC에 설치된 Chrome 브라우저 창으로만 열려요(다른 브라우저 창은 CGV가 막아요). Chrome이 없으면 먼저 설치해 주세요.
      3. 
    
    3. 설정 넣기
      위에서 받은 config.json으로 폴더 안의 같은 이름 파일을 바꿔요.
      4. 
    
    4. 미리 보기(선택)
      로그인 없이 어떤 회차를 고를지만 확인해요. 그 폴더에서 실행하세요.
      
      
      python megabox_helper.py --dry
      5. 
    
    5. 실행
      처음엔 열린 창에서 로그인하면 자동으로 이어가요. 좌석이 골라지면 소리가 나고 멈춰요. '다음'은 직접 눌러 결제하세요.
      
      
      python megabox_helper.py
      6. 
  
    

    


    
  
    쓰기 전에
    
  
    메가박스·롯데시네마·CGV 이용약관은 자동 프로그램 사용을 금지해요. 내 예매에 가끔만 쓰고, 짧은 간격으로 반복 확인하지 마세요. 계정 제재 책임은 쓰는 사람에게 있어요. 로봇 확인과 결제는 프로그램이 대신하지 않아요.
